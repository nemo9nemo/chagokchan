# 개발 기준 산출물 검사 기록

검사 기준일: 2026-10-07 / 상태: 산출물 구조·참조 검사 통과

scripts/verify-artifacts.mjs를 Node 24.19.0으로 실행했다. JSON 형식, 로컬 파일 링크, OpenAPI 내부 참조·operation ID·경로 인자·변경 요청 CSRF/JSON, 요구·정책·TC 참조, 정책 수치·쿠키·응답 projection, ERD 원본 일치, 등록 산출물의 존재를 확인했다. 성인 개인 범위 확정 후 정책 0.2.0·ERD v0.3의 가입 입력/상태·본인 전용 확인 필드·C01 해소도 다시 검사했다.

수치·시각·기준 파일 합성 SHA-256은 [실행 결과 JSON](artifacts-check-2026-10-07.json)을 따른다. SHA-256은 정렬한 상대 경로와 LF로 정규화한 UTF-8 텍스트를 합친 기준 파일 식별자다. 검사 입력 목록도 결과에 기록했다.

확인 범위는 요구 16개·정책 ID 19개·API 동작 54개·계획 TC 34개다. ERD는 앱 엔티티 18개+외부 Auth 참조 3개, 관계 42개, 문서 내 도표 3개와 원본의 일치를 확인했다.

재실행 명령: 지정한 Node 24 실행 파일로 node scripts/verify-artifacts.mjs. 외부 패키지·서비스 연결 없이 수행하는 산출물 검사다.

앱·DB·RLS·E2E·기기·복원·부하 검사는 미실행이고 34개 TC는 모두 not_run이다. 전체 OpenAPI validator와 Mermaid 렌더링도 미실행이며 문법·보안·기능 검증 통과로 확대 해석하지 않는다.

개발 환경 관측: PATH Node 22.14.0, 번들 Node 24.19.0, pnpm 11.19.0, Docker CLI 29.1.3. Docker 엔진 연결 실패와 설정 파일 접근 오류를 관측했으며 DB 실행 준비는 아직 확인 전이다. 다음 S04에서 실제 로컬 실행 경로·Docker·Supabase CLI·앱/DB 시작을 확인한다.
