# 포도알 칭찬 스티커 앱 — 시장조사

조사일: 2026-10-07 / 범위: 국내 칭찬 스티커 앱, 학급용 웹, 해외 가족 보상 앱, 개인 습관 앱, 지인 응원·목표 공유 서비스

현재 제품 방향은 셀프 칭찬과 계정 연결이다. 목표마다 개인 포도송이와 공유 포도송이를 따로 만들고, 공유판은 해당 목표의 주인이 지인에게 칭찬을 받는 용도다. 기존 12개 비교에 사회적 응원 관련 3개 서비스를 추가했다. 최신 기획은 [v0.2](product-plan-v0.2.md)다.

공식 서비스 페이지와 앱 스토어의 개발자 설명을 중심으로 조사했다. 표의 기능·가격은 공개 설명에서 확인한 내용이며, 설치 후 사용성을 검증한 결과는 아니다. 가격과 제공 기능은 국가·구매 경로·시점에 따라 달라질 수 있다. 스토어에 여러 구매 항목이 표시된 경우 실제 구매 화면의 적용 조건까지 확인한 것은 아니다.

## 기획에 바로 반영할 발견

1. **포도알 칭찬판 자체는 이미 존재한다.** 국내 앱에 포도송이 테마가 있으며, 교실용 웹에도 공동 포도알 칭찬판이 있다. 포도 모양만을 독자적인 차별점으로 주장하기 어렵다. [포도알 앱](https://apps.apple.com/kr/app/%EC%B9%AD%EC%B0%AC%EC%8A%A4%ED%8B%B0%EC%BB%A4-%ED%8F%AC%EB%8F%84%EC%95%8C-%EC%82%AC%EA%B3%BC%EB%82%98%EB%AC%B4-%EC%8A%A4%ED%8B%B0%EC%BB%A4%ED%8C%90-%EC%B9%AD%EC%B0%AC%EC%8A%A4%ED%83%AC%ED%94%84/id6808977509), [와르르멘토](https://wrrmentor.com/)
2. **칭찬판·메모·보상·공유도 경쟁 제품에 있다.** 새 앱의 가치는 이 기능들의 존재보다, 선택한 사용자가 더 쉽게 반복해서 쓸 수 있는지로 검증해야 한다. 3. **사용자 대상에 따라 제품이 달라진다.** 가족용은 아이와 보호자의 역할, 교실용은 다수 학생 관리와 전체 화면, 개인용은 빠른 기록과 누적 확인이 중심이 된다. [Joon](https://www.joonapp.io/), [ClassDojo](https://www.classdojo.com/points/), [HabitKit](https://habitkit.app/help/getting-started/install-habitkit-and-create-your-first-habit)

### 현재 방향에서 우선 비교할 제품

- **굿잡:** 국내 칭찬보드와 지인 공유가 현재 콘셉트와 직접 겹친다. 개인·공유 개수가 어떤 방식으로 반영되는지는 실제 사용 흐름에서 추가 확인한다.
- **HabitShare:** 목표별 공개와 지인 연결을 비교한다.
- **Finch:** 친구에게 응원하기, 받은 응원을 확인하기, 개인의 실천을 이어가기 흐름을 비교한다.
- **Podo:** 목표별 빠른 셀프 기록과 하루 한 번 기록 규칙을 비교한다.

### 차별화 가설 업데이트

계정 연결·응원·목표 공개 자체는 이미 시장에 있다. 이번 기획의 가설은 **목표마다 내가 인정한 실천과 지인이 인정한 순간을 각각의 포도송이로 모으는 경험**이다. 현재 공개 자료만으로 경쟁 제품에 이 조합이 없다고 단정하지 않는다.

검증 질문은 ‘개인 7알·공유 3알을 쉽게 이해하는가’, ‘지인의 칭찬이 내 실천을 대신하지 않아도 충분히 기쁜가’, ‘목표별로 칭찬받을 사람을 고르는가’, ‘칭찬을 주고받는 관계가 반복 사용으로 이어지는가’다.

## 대상 확정 전 검토한 기획 가설

아래 대상 비교는 초기 탐색 기록이다. 현재 중심 대상은 셀프 칭찬 사용자이며 지인의 칭찬을 받을 수 있는 목표별 공유판을 함께 기획한다.

**공통 제안:** 처음 보는 사람도 판을 만들고, 포도알을 붙이고, 완성된 판을 남기는 과정을 바로 이해할 수 있게 설계한다. 이 사용 흐름의 속도와 만족도를 직접 경쟁 앱과 비교한다.

| 대상 후보 | 집중할 문제 | 차별화 후보 — 아직 검증하지 않은 가설 |
| --- | --- | --- |
| 부모·아이 | 바쁜 순간에 칭찬을 빠르게 주고 함께 성취를 확인 | 쉬운 칭찬 입력, 가족이 함께 보는 화면, 완성된 포도송이와 칭찬 기록 모음 |
| 교사·학원 | 여러 학생에게 빠르게 부여하고 수업 중 표시 | 학생·모둠·학급별 판, 일괄 부여, 큰 화면, 출력과 학기별 보관 |
| 개인 | 작은 실천을 부담 없이 인정하고 다시 이어가기 | 기록 방식의 유연함, 완료한 판 수집, 쉬운 다시 시작 |

빠른 입력·기록 보관 등은 다른 앱에도 있을 수 있다. 현재 확인된 경쟁 제품 대비 독점 기능을 찾았다고 결론내리지 않는다. 우선 한 대상의 실제 사용 시나리오로 차이를 검증하는 것이 제안의 핵심이다.

## 가격·운영 판단

- 국내 단순 칭찬판에서 광고 제거와 평생 구매 사례를 확인했다. 새 앱도 기본 칭찬 흐름을 무료로 제공하고 테마·추가 편의 기능의 일회성 구매를 검토할 수 있다. 이는 가격 확정이 아닌 가설이다.
- 현재 기획에는 계정과 지인 칭찬의 동기화가 포함된다. 일회성 테마 구매와 지속 서비스 구독은 실제 운영 비용·사용 가치로 검토한다. 가상 펫·게임 콘텐츠가 있는 Joon과 기능·운영 비용이 같은 수준이라고 가정하지 않는다.
- 광고 노출 정책은 빠른 칭찬 입력과 받은 칭찬을 보는 경험에 연결해서 정한다. 경쟁 제품의 무료 표시가 광고 없음이나 모든 기능 무료를 뜻하지는 않는다.

## 조사 한계와 후속 조사

- 시장 규모·매출·활성 사용자·다운로드 추정은 이번 자료에서 산출하지 않았다. 검색된 경쟁 제품 수와 스토어 평가 수로 수요 규모를 추정하지 않는다.
- 앱의 기능과 가격은 개발자 공개 설명이다. 설치, 계정 생성, 구매, 가족 초대, 동기화 테스트는 수행하지 않았다.
- 포도알 앱과 Podo의 일부 정보는 공식 스토어의 검색 색인으로 확인했다. 포도알 앱 상세 페이지 직접 열기는 실패했으므로 실제 화면·구매 조건은 후속 확인 대상이다.
- Star Chart Kids는 같은 이름의 다른 앱과 구분하여 starchartkids.com의 제품만 다뤘다. 로컬·클라우드 동작은 소개 문구만으로 확정하지 않았다.
- iRewardChart는 과거 관련 자료가 검색됐으나 이번 조사에서 현재 공식 스토어 페이지를 검증하지 못해 비교표에서 제외했다.
- stickK의 응원자 설명은 공식 FAQ의 검색 색인에서 확인했다. 응원자 페이지 직접 열기는 403 응답으로 실패했으며 목표별 공개 범위는 공식 페이지를 직접 확인했다.
- 다음 조사 우선순위: 굿잡·HabitShare·Finch의 셀프 기록·연결·지인 칭찬 흐름 비교 → 목표별 개인/공유 분리의 이해도 확인 → 목표 사용자 5–10명의 사용 상황 확인 → 핵심 차별화와 유료화 판단.
