# MVP 요구사항과 수락 기준

2026-11-03 사용자 후속 결정: 초기 공개 웹 베타의 REQ-001 로그인 제공자는 Google만이다. 이메일 OTP는 발신 설정을 갖춘 후 추가한다. 만 19세 이상 자기 확인·최초 가입·현재 세션·탈퇴 기준은 유지한다. 아래 Google·OTP 병기는 전체 후속 범위이며 초기 베타 완료에 OTP를 요구하지 않는다.

버전: 0.2.0 / 기준일: 2026-10-07 / 상태: 개발 기준

첫 출시는 성인 개인 사용자 중심으로 확정했다. 한국 가입 기준은 만 19세 이상 자기 확인이며 [가입 정책](../policies/audience-and-signup.md)을 따른다. 확정 사용자 요구는 셀프 칭찬, 목표별 개인/공유 분리, 내 목표에 지인의 칭찬, 계정 연결, 확장 가능성이다. 플랫폼·로그인·보안·배포의 기존 결정을 상세 수락 기준으로 연결한다.

개발 중에는 로그인 화면 없이 로컬 가상 사용자로 이용하고, 실제 로그인 연동·테스트·실사용은 오픈 준비 시점부터 진행한다. 출시용 REQ-001은 유지하며 개발 적용 경계는 NFR-005와 [로컬 개발](../development/local-development.md)을 따른다.

2026-11-03 사용자 결정: 1차 로컬 무로그인 완료 범위를 유지하고, 2차는 실제 로그인과 **반응형 웹앱 공개**로 진행한다. PC·모바일 브라우저에서 설치 없이 이용하며 PWA 홈 화면 추가는 선택이다. Android/iOS 설치형·스토어는 사용자 재요청 전까지 현재 범위 밖이다. [ADR-0010](../decisions/ADR-0010-webapp-release.md) · [출시 실행안](../launch-and-growth-plan.md) · [서버·DB 재조사](../webapp-infrastructure-research-2026-11-03.md)

## 출시 범위와 후속 기능

첫 버전: 계정·목표·개인/공유판·초대/연결/권한·칭찬 정리·앱 내 소식·지난 회차·삭제·PWA.

후속 후보: 미성년자·보호자·가족·교실·조직 계정, 그룹·공동 소유·보기 전용 역할·받는 사람 승인 후 반영·개수 제외 복구·공유 문구 편집·사진·댓글·배지·푸시·네이티브·위젯·AI·결제·다른 이메일 병합. 후속 기능은 현재 요구의 자동 완료 조건에 포함하지 않는다. 도입 시 정책·모델·권한을 확장한다.

구현 상태는 [진행표](../development/backlog.md)를 따른다. 핵심 로컬 기능과 인증 서버 기반 일부는 구현·검증했으며 실제 제공자 로그인·전체 제품 수락·운영 배포는 미완료다. 설계·계약 검사의 완료와 기능 수락 TC의 실행 통과를 구분한다.

참조: [정책](../../policies/app-policy.json), [제품 규칙](../policies/product-rules.md), [API 계약](../../contracts/openapi.json), [개발 절차](../development/README.md).
