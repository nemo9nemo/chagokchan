# 차곡찬 출시 마케팅 준비물

작성일: 2026-10-19 / 상태: 문안 준비. 외부 게시·발송·광고 집행 없음.

기준은 [출시·수익화·마케팅 실행안](../launch-and-growth-plan.md)과 [브랜드](../branding/brand-guide.md)다. 아래 베타 문안은 2차 실제 로그인·지원/개인정보 처리 준비 뒤 사용한다. 현재 로컬 무로그인 앱을 외부에 공유하는 안내가 아니다.

무료+광고는 [수익 모델 비교](../free-with-ads-plan.md)의 검토안이다. 초기 베타는 무료로 제안하되 광고·추가 테마·광고 제거 상품이 이미 제공된다고 안내하지 않는다. 광고 수익 시험을 시작하면 실제 노출·선택·보상 조건을 별도로 명확히 알린다.

## 소개 문구와 공개 안내 구성

**차곡찬 — 오늘의 작은 실천을 칭찬으로 모아요.**

나를 칭찬한 기록과 지인에게 받은 칭찬을 목표마다 따로 쌓아 보세요. 혼자 조용히 기록해도 좋고, 원하는 목표만 선택한 사람과 나눠도 좋아요.

소개 페이지 구성안:

1. 실제 앱을 보여 주는 15초 가상 데이터 데모와 한 문장 소개.
2. “내 실천은 내가 기록해요” — 목표·셀프 칭찬·태그·짧은 메모.
3. “받은 응원은 따로 모아요” — 개인/공유 개수를 구분하고, 사람 연결 뒤 판 권한을 별도로 선택.
4. “원할 때 정리해요” — 칭찬 취소, 지인 차단, 목표 휴지통·복구.
5. 대상·지원 환경·지원/개인정보/계정 삭제 안내와 실제 작동하는 시작 동선.

현재 추가 구매 테마·회고·푸시·위젯·성과 이미지 내보내기·자동 오프라인 저장은 미구현이므로 출시 기능처럼 광고하지 않는다. 목표를 만든 뒤 공유판을 추가하는 기능도 미구현이다. 공유판은 생성 때 선택하는 현재 흐름에 맞춘 데모를 쓴다.

## 짧은 영상 3편 대본

| 편 | 화면/자막 | 마무리 |
| --- | --- | --- |
| 1. 나를 칭찬할 이유 | 0~3초 “오늘 별일 안 했다고요?” → 3~9초 가상 목표 ‘책 한 쪽’에서 셀프 칭찬 1개 저장 → 9~15초 “작은 실천 하나도 남겨요” | “차곡찬, 내 칭찬을 차곡차곡.” |
| 2. 두 종류의 칭찬 | 0~4초 개인판 ‘내 기록’ → 4~10초 공유판 ‘받은 칭찬’ 전환 → “친구의 응원과 내 기록은 따로 쌓여요” | 실제 운동량·목표 달성률로 합산하지 않는 화면 |
| 3. 내 속도로 기록 | 0~5초 “매일 완벽하지 않아도” → 5~11초 휴식 태그와 짧은 가상 메모 → 11~15초 “나를 인정하는 기록 하나” | 치료·집중력 개선·습관 성공률 등 입증하지 않은 효능 문구 없음 |

사용자 기록·초대 코드·이메일을 촬영하지 않는다. 전부 가상 목표와 가상 문구로 만들고 화면의 비밀은 숨긴다. 포도 외 테마도 같은 브랜드로 표현한다.

## 2차 성인 베타 모집 문안

> 작은 실천을 스스로 칭찬하고 싶은 분을 찾고 있어요.
>
> 차곡찬은 목표마다 나를 칭찬한 기록과 지인에게 받은 응원을 따로 모으는 앱이에요. 먼저 성인 사용자를 대상으로 모바일 웹 베타를 준비하고 있어요.
>
> 한국 기준 만 19세 이상이며, 약 2주 동안 사용하면서 첫 기록·불편한 점·계속 쓸 이유를 알려 주실 분이면 좋아요. 지인 초대는 선택이고, 개인 기록을 공개할 필요는 없어요.
>
> 참여 방법과 실제 지원·개인정보 안내는 베타 환경이 준비된 뒤 함께 안내할게요.

개발자 계정의 Play 비공개 테스트 모집에는 해당 테스트의 연속 참여 기간과 실제 테스트 링크를 별도로 안내한다. 좋은 리뷰·긍정 평가를 참여 조건으로 삼지 않는다. 모집처의 홍보 규칙을 확인하고 자동 대량 발송하지 않는다.

## 사용자 인터뷰 질문

1. 최근 일주일에 스스로 잘했다고 느낀 작은 일이 있었나요? 지금은 어디에 남기나요?
2. 첫 목표와 칭찬 하나를 도움 없이 남겨 보세요. 망설인 지점은 어디였나요?
3. 내 기록과 받은 칭찬이 어떻게 다른지 설명해 주실 수 있나요?
4. 어떤 목표를 누구에게 보여 주고 싶나요? 공유하고 싶지 않은 것은 무엇인가요?
5. 다음 주에도 열어 볼 이유가 있나요? 없으면 무엇이 부족한가요?
6. 추가 테마 일회 구매, 회고 기능 구독, 무료 기본 기능 중 무엇이 가치 있나요? 제시 가격을 보고도 선택이 같은가요?
7. 원하지 않는 칭찬이나 연결을 정리하는 방법을 찾을 수 있나요?

기록 본문을 보여 달라고 요구하지 않는다. 관찰·인터뷰 저장 전 목적과 보관 범위를 알리고 동의를 받는다. 표본 수와 부정 의견을 함께 기록하며 구매 의향을 실제 결제로 세지 않는다.

## 첫 4주 콘텐츠 목록

| 주 | 콘텐츠 1 | 콘텐츠 2 | 콘텐츠 3 |
| --- | --- | --- | --- |
| 1 | ‘책 한 쪽’ 셀프 칭찬 데모 | 왜 개인/받은 칭찬을 나눴는지 | 가상 문구로 적는 오늘의 칭찬 5가지 |
| 2 | 휴식도 남기는 기록 | 연결과 판 권한의 차이 | 사용자 관찰로 고친 불편 1개(동의한 비식별 예시만) |
| 3 | 한 목표만 선택해 응원받기 | 메모 없이도 남기는 칭찬 | 목표를 잠시 보관하고 다시 시작하기 |
| 4 | 개인판과 공유판 전환 데모 | 베타에서 배운 점과 다음 수정 | 실제 출시 환경이 준비된 경우에만 시작 방법 안내 |

각 게시물은 제작→개인정보 확인→실제 지원 기능 확인→사용자 게시 승인 순서로 준비한다. 이 문서를 만든 것으로 게시 승인을 받거나 외부 메시지를 발송한 것으로 간주하지 않는다.
