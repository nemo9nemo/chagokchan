# 복원 뒤 모든 과거 세션 무효화

2026-11-17 / W14-C2b / REQ-010·NFR-001·NFR-004 / POL-DELETE-003·POL-ACCESS-001 / TC-RESTORE-SESSION-001

이전 백업은 탈퇴하지 않은 사용자의 로그아웃 이전 세션도 포함할 수 있다. 삭제 계정의 최신 원장을 재적용하는 것만으로 다른 사용자의 폐기 세션을 무효화했다고 볼 수 없다. 외부 연결 전 복원 사본의 세션·갱신 토큰·미완료 인증 흐름·일회용 토큰·앱 재인증 grant를 모두 지우고 새 로그인을 요구한다.

이번 구현은 기존의 표시된 임시 로컬 복원 DB에만 적용한다. 원본 DB·클러스터 역할·실제 호스팅 Auth를 변경하지 않는다. pg_dump/pg_restore와 기존 삭제 원장 검사를 확장해 비탈퇴 대조 계정을 백업 뒤 실제 Auth 로그아웃하고, 복원 직후 과거 세션이 존재하는 것과 무효화 뒤 guard 거절을 모두 확인한다. 사용자·목표·칭찬·기존 데이터와 역할은 보존한다. 마이그레이션 개수는 고정 숫자 대신 백업 시점의 실제 이력을 비교한다.

호스팅에서는 같은 차단 절차와 공급자의 현재 Auth 설정·Google 재로그인·키/원장 재적용·작업자 재개를 별도로 수락해야 한다. 현재 로컬 도구의 통과만으로 운영 복원이나 TC-DELETE-004를 완료 처리하지 않는다. 목표 파기·취소 본문 원장과 접수 직후 장애 경계·내구성 저장소/주기는 W14-C2에 계속 남긴다.
