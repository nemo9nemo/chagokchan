# ADR-0002 — 성인 개인 사용자 중심의 첫 출시

날짜: 2026-10-07 / 상태: 채택 / 관련: C01, REQ-001, NFR-001/004, W02/W05/W08

## 사용자 결정

사용자는 첫 출시 대상을 “성인 개인 사용자 중심”으로 확정했다. [ADR-0001](ADR-0001-development-baseline.md)의 가입 범위 가정과 답변 대기를 해소한다. 셀프 칭찬·독립 개인/공유판·지인의 칭찬·목표별 권한·추후 Git 연결은 기존 기준을 유지한다.

## 개발 선택

한국 첫 출시의 가입 기준은 만 19세 이상 자기 확인으로 정한다. [민법 제4조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026056227)의 성년 기준을 참고했다. 사용자가 연령 수치나 본인확인 수단까지 직접 지정한 것으로 기록하지 않는다.

생년월일·전화 본인확인·신분증을 수집하는 방식은 초기 개인 칭찬 경험에 필요한 데이터와 운영 부담을 늘린다. 첫 버전은 확인 시각과 정책 버전만 보관한다. 자기 선언은 실제 나이나 신원에 대한 검증 결과를 제공하지 않는다.

Auth 인증 후 새 사용자에게 가입 확인 화면을 제공하고 명시적 제출 이후 앱 계정·프로필을 생성한다. 기존 로그인은 최초 확인 기록을 덮어쓰지 않는다. 가입을 마치지 않은 Auth 데이터의 정리도 설계 범위에 포함한다.

## 변경 영향

- 정책 버전 0.1.0 → 0.2.0. 성인 범위 상태를 confirmed로 기록한다.
- ERD v0.3: app_users에 adult_confirmed_at·registration_policy_version을 추가한다. 새 테이블은 없다.
- API: bootstrap 입력, 인증 후 account_state, 가입 미완료 오류·정책 버전 충돌을 구체화한다.
- 화면·REQ·TC·작업 목록·등록부를 같이 갱신한다. 아동·보호자·교실 계정은 후속 확장 후보로 관리한다.
- 성인 확인은 공개 약관·개인정보 관련 동의를 대체하지 않는다. 공개 정책은 실제 운영 정보가 준비된 뒤 작성한다.

## 검증과 상태

산출물 형식·참조·정책/API/ERD 일치를 정적으로 확인한다. TC-AUTH-004와 TC-AUDIENCE-001은 구현 후 실행하며 지금 통과로 기록하지 않는다. 현재 단계는 S03 설계 기준이고 다음 단계는 S04 로컬 개발 기반이다.
