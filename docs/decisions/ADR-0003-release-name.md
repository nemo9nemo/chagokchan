# ADR-0003 — 차곡찬 출시명과 영문 표기

날짜: 2026-10-08 / 상태: 채택 / 범위: 브랜드·프로젝트 이름

사용자는 후보 중 차곡찬을 선택하고 영문 표기 방법을 요청했다. 한글 이름은 사용자 확정으로 기록한다.

영문 표시 이름은 한글 발음에 기반한 Chagokchan으로 채택하고, 향후 개발 프로젝트·저장소·패키지 slug는 chagokchan으로 통일한다. 이 영문 표기는 일관된 브랜딩을 위한 개발 선택이며 사용자가 이미 별도로 지정한 철자로 기록하지 않는다. 일반 표기·병기·워드마크·소개 문구의 기준은 [브랜드 가이드](../branding/brand-guide.md)에 둔다.

포도는 교체 가능한 표현 테마다. 브랜드명 결정은 기존 기록·권한·정책 수치·인증 쿠키·DB 테이블을 바꾸지 않는다. 공개 앱 제목과 기획 문서·API 메타데이터·등록부의 임시 이름을 갱신한다.

공개 웹 검색은 예비 관측이며 상표·스토어 내부·도메인 확인 상태는 그대로 미확인이다. 이번 선택으로 Git 저장소·계정·도메인·서비스가 만들어지지 않는다. 실제 개설은 해당 개발·출시 작업에서 진행한다.

문서·JSON·링크·상호 참조 검사를 수행하고 결과를 등록부의 artifact_report에 남긴다. 기능 검증은 구현 후 실행한다.
