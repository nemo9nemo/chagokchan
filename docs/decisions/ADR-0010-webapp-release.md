# ADR-0010 — 공개 출시 대상을 웹앱으로 변경

결정일: 2026-11-03 / 상태: 사용자 결정 반영 / 작업: W27-A

## 근거와 결정

사용자 요청: “현재 진행사항 확인. 앱으로 출시를 웹앱으로 변경 진행할 것. 서버, DB 등 어떻게 할지 다시 시장조사 필요”. 10-29의 W22-D는 조건부 비교였으며 이번 명시 요청으로 출시 범위를 변경한다.

PC·모바일 브라우저에서 URL로 이용하는 반응형 웹앱을 출시한다. PWA 홈 화면 추가는 선택 기능으로 유지하며 설치를 요구하지 않는다. Android·iOS 설치형/스토어 작업 W23/W24는 현재 범위 밖으로 유예하고, 사용자가 다시 요청할 때 재검토한다. 웹 공개 뒤 자동으로 스토어 개발을 시작하지 않는다.

핵심 목표·칭찬·선택 공유, 만 19세 이상 자기 확인, 서버 세션·RPC/RLS와 개발 중 무로그인 경계는 유지한다. 실제 Google/OTP·가입·갱신·로그아웃·재인증/탈퇴·여러 계정 권한·웹 실기기·삭제/복원·운영 검증은 공개 전 필수다. 수익화는 부차 목표다.

## 서버와 DB

[11-03 시장조사](../webapp-infrastructure-research-2026-11-03.md)의 우선 검증 후보는 Vercel + Supabase다. Cloudflare·Lightsail·Render와 Neon/직접 운영을 비교했다. 후보 권고를 서비스 개설·요금제 승인으로 해석하지 않는다. 운영 주체·지원·도메인·월 예산·공급자는 실제 설정 전에 정한다.

현재 Next.js 웹/API·Supabase Auth/PostgreSQL을 개발 기반으로 재사용한다. 신규 API/DB 이행 없이 출시 채널을 변경하므로 ERD·OpenAPI·기존 마이그레이션을 수정하지 않는다. 배포의 Node 패치 고정·바인딩·환경 검사 호환성은 W27-B에서 별도 구현·검증한다.

배포 채널·개발 마일스톤은 `policies/development-policy.json`에서 관리한다. 가입 연령·약관/동의 내용·제품 수치 변경이 없으므로 `app-policy.json`의 가입 정책 버전 0.2.0과 `.env.example`·OpenAPI 버전은 올리지 않는다.

## 영향과 완료 범위

기존 모바일 웹/PWA → Android → iOS 순서는 현재 실행안에서 해제한다. 과거 사례·스토어 비용 자료·W22-D 증거는 당시 기록으로 보존하며 현행 지시와 구분한다. 현재 순서는 배포 호환성/실제 인증 준비 → 분리 환경·운영 준비 → 웹 수락·베타 → 웹 공개다.

이번 완료는 요구·개발 정책·설계 설명·검증 계획·진행표·등록부·시장조사의 문서 반영이다. 로그인·공개 페이지·배포 설정 구현이나 클라우드/실제 인증 수락 완료가 아니다.
