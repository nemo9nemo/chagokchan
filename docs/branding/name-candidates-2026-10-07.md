# 출시명 검토 기록과 테마 독립 원칙

작성일: 2026-10-07 / 갱신일: 2026-10-08 / 상태: 차곡찬 선택 완료·후보 비교 기록

## 확정한 방향

실제 앱 출시를 목표로 이름을 고른다. 사용자는 성인 개인 중심이며 셀프 칭찬과 지인의 응원이 핵심이다. 포도는 교체 가능한 표현 테마다. 이름은 칭찬·작은 성취·응원을 담고 특정 과일·그림·스티커 모양에 의존하지 않는다.

2026-10-08 사용자가 차곡찬을 출시명으로 확정했다. 영문 표시 Chagokchan·개발 slug chagokchan은 [브랜드 기준](brand-guide.md)을 따른다. 아래 표는 선택 전 비교 기록이며 이름 선택과 상표·도메인 확보 상태는 별도로 관리한다.

## 추천 후보

평가는 이름의 의미·발음·성인 사용자 적합성·확장 여지를 고려한 기획 판단이다.

| 순위 | 후보 | 담는 의미 | 장점 | 검토할 점 |
| --- | --- | --- | --- | --- |
| 1 | 차곡찬 | 칭찬을 차곡차곡 모으기 | 세 음절, 개인/공유 기록과 잘 맞고 여러 테마로 확장 가능 | 합성 이름이므로 소개 문구로 뜻을 연결 |
| 2 | 칭찬함 | 나를 칭찬함 + 칭찬을 담는 함 | 기능을 바로 이해하기 쉬움, 내 칭찬과 받은 응원 모두 포함 | 일상 표현·게시판 명칭 등과 검색 결과가 섞일 수 있음 |
| 3 | 해냈음 | 오늘의 작은 시도와 성취를 인정하기 | 친근한 말투, 성인 개인의 일상 기록에 어울림 | 결과를 완수해야만 사용할 수 있다는 인상을 피하도록 소개 |
| 4 | 토닥함 | 나를 토닥이고 서로 응원을 담기 | 부드러운 분위기, 응원·메모·회고로 확장 가능 | 감정 일기 앱으로 이해될 수 있어 칭찬판 소개 필요 |

선택한 이름과 소개 문구 초안:

- 앱 이름: **차곡찬**
- 앱 소개: **나를 칭찬하는 습관**
- 브랜드 문구: **작은 실천, 차곡차곡 칭찬.**
- 영문 표시: **Chagokchan**
- 내부 프로젝트 slug: chagokchan

실제 개발 파일·Git 저장소를 만들 때 chagokchan을 사용한다. 아직 저장소·도메인·계정을 개설한 상태는 아니다. 소개·브랜드 문구는 출시 카피 검토 전의 초안이다.

## 1차 중복 검색 기록

2026-10-07에 정확한 이름과 앱·서비스 조합으로 공개 웹 검색을 수행했다. 칭찬함·차곡찬은 apps.apple.com/play.google.com 범위 검색도 포함했다.

| 후보 | 이번 검색 관측 | 확인하지 않은 범위 |
| --- | --- | --- |
| 차곡찬 | 동일 이름의 앱 목록을 검색 결과에서 찾지 못함 | 스토어 내부 전체 검색·KIPRIS 권리 기록·도메인 등록 가능 여부 |
| 칭찬함 | 일상 표현 및 [교직원 칭찬함 게시판](https://graduipsi.knsu.ac.kr/chonghak/opinion/compliment.do) 명칭이 검색에 노출됨. 동일 이름 앱 목록은 찾지 못함 | 동일·유사 상표, 국가별 스토어·도메인 |
| 해냈음 | 일반 문장에 쓰인 표현이 검색에 노출됨. 앱 브랜드로 확인된 결과는 찾지 못함 | 스토어 내부·동일/유사 상표·도메인 |
| 토닥함 | 이번 검색에서 확인할 수 있는 동일 이름 앱·서비스 결과를 찾지 못함 | 스토어 내부·동일/유사 상표·도메인 |

검색 결과의 부재는 사용 가능·상표 미등록·이름 독점 가능을 의미하지 않는다. 검색 엔진에 노출된 범위만 확인한 상태다. 교직원 게시판은 검색 결과 제목을 확인했으며 원문 직접 열람은 실패했다.

[KIPRIS 공식 상표 검색](https://www.kipris.or.kr/khome/search/searchResult.do?tab=trademark) 화면은 확인했으나 후보별 출원/등록 기록·유사 호칭·지정상품 상세 검색은 아직 수행하지 않았다. 출시명 선택 때 한글·영문 후보와 유사 이름을 확인하고 실제 앱/서비스 범위에 맞춰 판단한다. 앱스토어 내부 검색, 도메인·주요 계정 이름 확인은 별도 기록한다.

## 테마와 제품의 관계

서비스 브랜드와 기능 이름은 내 목표·개인 칭찬판·공유 칭찬판·칭찬 기록·회차를 사용한다. 포도·꽃·별 등은 테마의 시각 표현 후보이며 기본 테마 확정이나 추가 테마 구현 완료를 뜻하지 않는다.

테마를 바꿔도 목표·판·회차·칭찬 ID, 작성자·수신자, 본문·시각, 유효 개수·완성 이력·현재 권한을 유지한다. 테마의 모양이나 배치가 목표 개수와 칭찬의 의미를 바꾸지 않는다. 테마 변경만으로 새 회차를 만들지 않는다.

첫 구현부터 집계·권한과 시각 표현을 분리한다. 여러 테마의 선택·저장 UI와 데이터 설정은 후속 기능에서 구체화한다. 포도 관련 내부 용어가 남아 있어도 외부 출시 브랜드를 그 이름으로 확정한 것으로 해석하지 않는다.
