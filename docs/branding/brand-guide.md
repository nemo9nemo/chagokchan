# 차곡찬 브랜드·영문 표기 기준

버전: 0.1.0 / 기준일: 2026-10-08 / 상태: 한글 이름 사용자 확정·영문 표기 기준 채택

한글 출시명 차곡찬은 사용자가 선택했다. 영문 표기는 한글 이름의 발음을 살려 Chagokchan으로 채택한다. 영문 이름·개발 slug는 일관된 사용을 위해 정한 표기 규칙이며 영문 소개 문구는 초안이다. [결정 기록](../decisions/ADR-0003-release-name.md)

| 용도 | 표기 |
| --- | --- |
| 한국어 앱·서비스 이름 | **차곡찬** |
| 영어 앱·서비스 이름 | **Chagokchan** |
| 발음 참고 | 차·곡·찬 / cha-gok-chan |
| 한국어·영어 병기 | 차곡찬 (Chagokchan) |
| 개발 프로젝트·향후 Git 저장소·패키지 slug | chagokchan |
| 대문자 워드마크 변형 | CHAGOKCHAN |
| 한국어 소개 문구 초안 | 나를 칭찬하는 습관 |
| 영어 소개 문구 초안 | Celebrate your small wins. |

일반 본문·스토어·소개 자료는 Chagokchan으로 통일하고 개발 이름은 소문자로 쓴다. 단어 중간 대문자·띄어쓰기·하이픈을 새로운 공식 표기로 섞지 않는다. 대문자 워드마크는 같은 이름의 디자인 변형이다.

차곡찬은 칭찬을 차곡차곡 모으는 서비스다. 특정 과일·그림에 브랜드를 묶지 않는다. 테마 변경은 목표·판·회차·기록·집계·권한을 유지한다. 기존 도메인 용어나 인증 쿠키 이름을 브랜드명 결정만으로 변경하지 않는다.

2026-10-08 Chagokchan의 공개 웹 검색과 앱스토어 도메인 범위 검색에서 결과가 반환되지 않았다. 상표·스토어 내부 등록 가능 여부·도메인 가용성을 확인한 결과는 아니다. 현재 미확인 상태는 [등록부](../development/artifact-register.json)에 유지한다. 실제 저장소·도메인·서비스를 개설할 때 해당 기록을 갱신한다.

이전 후보와 한국어 검색 범위는 [이름 검토 기록](name-candidates-2026-10-07.md)에 보존한다.
