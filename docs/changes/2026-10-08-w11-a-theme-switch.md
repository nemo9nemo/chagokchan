# W11-A 교체 가능한 테마 토큰과 화면 전환

- 작업 ID·제목: W11-A 교체 가능한 테마 토큰·정원/포도 전환
- 날짜·담당: 2026-10-08 / Codex
- 변경 목적·전후 동작: CSS 색상 변수를 숲/잎/크림 같은 현재 팔레트 명칭에서 텍스트·브랜드·표면 역할의 의미 중심 토큰으로 분리했다. 앱 헤더에 접근 가능한 화면 테마 스위치를 추가해 정원과 포도 팔레트를 현재 탭에서 전환한다.
- 관련 REQ / POL / TC: REQ-011·NFR-002 / POL-SEC-001 / TC-WEB-003
- 정책·데이터 영향: theme는 React 탭 상태와 문서의 `data-theme` 표시 속성으로만 적용한다. `localStorage`·`sessionStorage`·쿠키를 쓰지 않으며 API/RPC·목표·회차·칭찬·집계·권한을 변경하지 않는다. 테마 선택은 새 탭/새로고침에서 기본 정원 팔레트로 시작한다.
- 실행 환경·도구 버전: Windows 로컬, Node 24.19.0, pnpm 11.19.0, Next.js 16.4.0, local fixture Auth actor A
- 실행 명령 또는 수동 재현 단계: `scripts/project.ps1 -Task check`; `scripts/project.ps1 -Task build:check`; 로컬 앱에서 테마 스위치에 키보드 포커스를 둔 뒤 Space로 정원↔포도 전환
- 관찰 결과·증거 파일: W11-A 로컬 화면에서 목표 “오늘의 작은 수고”와 개인/공유판 `0/20` 상태를 전환 전후 유지했다. `aria-pressed` 0/1 상태와 포도 팔레트의 표면·브랜드색 변화를 확인했다. 서버 로그에는 읽기 GET만 있었고 전환으로 인한 API 쓰기는 없었다. client-app의 브라우저 저장소 사용은 검색 결과 0건이다. [검사 증거](../quality/reports/w11-a-theme-switch-check-2026-10-08.json)
