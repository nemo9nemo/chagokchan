# 복원 사본의 과거 인증 상태 무효화

W14-C2b / TC-RESTORE-SESSION-001. 백업 뒤 실제 로그아웃한 비탈퇴 사용자도 복원 사본에 과거 세션이 남는 것을 확인했다. 삭제 계정 원장 재적용과 별도로 모든 세션·갱신 토큰·미완료 인증 흐름·일회용 토큰·앱 재인증 grant를 원자적으로 무효화해 새 로그인을 요구한다. 기존 로컬 임시 DB 경계만 사용하며 원본/호스팅 DB를 변경하지 않는다.

전체 암호화 pg_dump/pg_restore·실제 소스 Auth 삭제/대조 로그아웃·복원 세션 재등장·전체 무효화/guard 거절·최신 원장 재적용·제품/원본/역할 보존·임시 대상 정리 9건과 check/unit 271·산출물 검사를 통과했다. 마이그레이션 수도 백업 시점 실제 값과 비교하도록 고쳤다. [검사](../quality/reports/w14-c2b-restore-session-check-2026-11-17.json). 호스팅 저장소/스케줄·목표/취소 원장·실제 Google 재로그인/운영 복원은 미완료다.
