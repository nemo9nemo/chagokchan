# 암호화 전체 백업과 삭제 계정 복원 차단의 로컬 검증

W14-C2a / REQ-010·NFR-001·NFR-004 / POL-DELETE-002·003 / TC-RESTORE-ACCOUNT-LOCAL-001

이전의 완료 ACK 재실행 검사와 별도로 실제 pg_dump/pg_restore를 수행하는 로컬 도구를 추가했다. 삭제 전 전체 DB 백업을 암호화한 뒤 격리 DB로 복원하고, 독립 최신 계정 원장을 재적용해 되살아난 데이터·세션을 제거한다. 원본 DB와 다른 계정은 보존한다.

검사에서 복원 관리자는 기존 NOLOGIN 소유자로 SET ROLE할 수 없어 초기 복원이 실패했다. 임시 대상에만 기존 로컬 클러스터 관리자를 사용해 원래 소유권을 보존했다. 실패·성공 실행 모두 원본과 기존 역할을 보존하고 실행별 임시 DB/파일을 정리했다. 원본에 새 관리 권한을 부여하거나 소유권을 풀지 않았다.

암호화/변조 단위 4개와 전체 로컬 Auth·백업·복원 통합 7개를 통과했다. 호스팅 스케줄·목표/취소 원장·운영 복원/작업자 재개는 미완료다. 별도 무료 운영 DB는 자동 승인 검토가 세션 검사 역할의 RLS 우회 권한 추가를 거절하여 SQL 3개에서 멈췄다. 사용자 0명·웹 배포 없음·스테이징의 동일 역할이 이메일/비밀번호/토큰을 읽지 못함을 확인하고 정확한 대상/권한의 승인을 요청했다. 거절된 권한 변경을 다른 도구로 우회하지 않았다.
