## 변경·이유

Claude 분업·승인 대기 조건을 사용자 명시 요청에 따라 Codex 직접 진행·검토로 바꿨다. AGENTS·도구 진입 문서·절차·브리프 양식·ADR-0007을 일치시켰다. 과거 Claude 리뷰와 W21의 모델 실행 전 403 시도는 이력으로 보존했다. 해당 403의 복구를 다음 작업으로 요구하지 않는다.

Codex가 W21의 고정 pnpm 선택·임시 RPC schema cache 대기·권한 경합 fixture 격리 변경과 호출 문맥·기존 실행 증거를 직접 검토했다. 해결되지 않은 변경 범위 결함을 발견하지 않았다. 동일 도구의 직접 검토이며 독립 교차 리뷰는 아니다. W21 로컬 완료 범위를 진행표·등록부·인계·README에 맞췄다. W09-D의 이미 완료된 로컬 적용/검증 상태도 ADR과 배포 안내에 맞췄다.

무료 핵심+선택형 꾸미기 보상 광고를 우선 검토안으로 추가했다. 실제 노출/DAU/eCPM 계산, 광고 위치·보상·데이터 경계, PWA와 앱 SDK 차이를 기록했다. 광고 도입을 확정하거나 실제 단가·수익을 검증한 것으로 표시하지 않는다. 유료 상품 가격은 비교 가설로 유지하며 마케팅 광고비와 앱 광고 수익을 구분한다.
