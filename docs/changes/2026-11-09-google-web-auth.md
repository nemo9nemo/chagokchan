# Google 웹 로그인·가입·갱신 기반

2026-11-09 / W12-C2a / REQ-001·NFR-001/004/005·POL-ACCOUNT-001/002·POL-SEC-001·POL-AUDIENCE-001·TC-AUTH-WEB-001

초기 베타를 Google만 제공하도록 요구·정책·계약에 반영했다. 로그인 시작 POST·PKCE S256·암호화 Host 흐름 쿠키·고정 서버 콜백, 최초 성인 확인 화면, 현재/전체 로그아웃 메뉴, 만료된 접근 토큰의 CSRF POST 갱신을 연결했다. 브라우저 Supabase 클라이언트나 관리 키를 추가하지 않았다. 로컬 무로그인 이용은 유지한다.

Auth 사용자와 DB 현재 세션·계정 상태를 검증한 뒤 Auth 쿠키를 발급한다. 다른 UUID/세션의 갱신과 다른 로그인 이후의 늦은 콜백을 거절하고 원래 30일 쿠키 만료를 보존한다. 초대 fragment는 즉시 주소에서 지우고 로그인 동안 짧은 수명의 암호화 쿠키에 보존한다. 갱신과 쓰기의 CSRF 준비를 직렬화하고 같은 요청 본문/멱등 키로만 재시도한다. 다른 탭의 로그아웃/계정 변경과 복귀 시 현재 계정을 확인하는 경계를 추가했다. 이 경계의 실제 다중 탭 브라우저 수락은 남아 있다.

전체 단위 231·lint/typecheck·build·격리 production HTTP 13, 실제 로컬 Auth/DB 8·로그아웃 회귀 6을 통과했다. 로컬 Auth 검사는 새로운 합성 사용자·실제 발급 세션으로 수행했으며 기존 제품 행·Auth 사용자/세션을 보존하고 검사 데이터를 정리했다. Google 코드 교환만 대체했으므로 실제 Google 통과는 0건이다. PC·모바일 크기의 비로그인 화면은 넘침·버튼 높이·콘솔을 확인했다. [검사 보고서](../quality/reports/w12-c2-google-web-auth-check-2026-11-09.json).

Docker Desktop의 기존 AF_UNIX 소켓 오류를 임시 디렉터리 보존·남은 Docker AI 프로세스 종료로 복구했다. DB 초기화나 원본 SQL 변경은 하지 않았다. 새 DB 마이그레이션은 없다.

실제 Google 설정·HTTPS/다중 탭·가입/초대/로그아웃 사용자 수락, 공개 정책·지원 페이지, 분산 제한, 탈퇴 재인증·독립 원장/복원, 운영 DB·배포는 후속이다. 현재 `/privacy`·`/terms`의 공개 내용은 W27-C에서 준비해야 한다. 공개 완료로 표시하지 않는다. Codex가 직접 소스·응답 제한·환경 분리·diff/비밀 제외를 검토하며 PR·필수 CI·병합 결과는 GitHub 기록을 따른다.
