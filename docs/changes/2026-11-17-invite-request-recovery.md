# 초대 요청 전송·재시도와 미리보기 대상 보호

2026-11-17 / W09-F / F-02 / REQ-005 / POL-CONNECT-001·POL-SEC-001 / TC-INVITE-RETRY-001

결과 불확실 시 보존한 attempt 때문에 재시도 버튼이 비활성화되던 결함을 고쳤다. 실제 전송 중에는 입력·취소·이동/중복 실행을 막고 실패 후에는 원래 초대·본문·키로 다시 확인한다. 미리보기 성공 시점의 초대에 요청을 고정하고 코드 수정 시 재확인하게 한다. 늦은 미리보기는 새 코드·닫기·앱 종료 뒤 반영하지 않는다.

불확실 요청 닫기는 기존 철회와 다름을 확인하며 실제 철회 API를 호출하지 않는다. 성공/닫기 시 임시 초대 참조를 정리하되 요청 성공만으로 별도로 발급한 본인 초대 비밀을 지우지 않는다. 공통 멱등/API·SQL·권한 계약은 유지한다.

고정 Node 24.22.1·pnpm 11.19.0에서 check(unit 264)·build:check, 실제 로컬 Auth 연결 RPC 13, 실제 브라우저의 합성 API 초대 28+공유 회귀 26(데스크톱/모바일 합계 54)을 통과했다. 소스/호출부·상태 정리·새 초대/재시도/취소 경계는 Codex가 직접 검토했다. 독립 교차 리뷰로 표시하지 않는다. 브라우저의 실제 API/DB 성공 저장·Google·배포 HTTPS/기기·운영 복원은 미실행이다.
