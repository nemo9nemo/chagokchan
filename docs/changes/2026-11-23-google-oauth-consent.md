# Google OAuth 동의 화면 등록

W12-C2b2 · REQ-001. 사용자가 Google 사용자 데이터 정책에 동의한 뒤 Chagokchan 프로젝트에서 ‘OAuth 구성 생성됨’을 확인했다. 차곡찬 앱 이름과 확정한 공개 지원 주소를 재조회했고, 대상은 외부, 게시 상태는 테스트 중이다.

스테이징 웹 클라이언트 폼에 Vercel 원본 주소와 스테이징 Supabase 콜백을 입력하고 값을 대조했다. 기존 Vercel 배포의 소스는 0143902이며 새 소스 업로드와 배포의 보류 상태는 유지한다. 스테이징 제공자 연결과 실제 Google 로그인 수락은 W12-C2b에서 추적한다.
