# 활성 세션 현재/전체 로그아웃 API

작업: W12-C1 / REQ-001·NFR-001 / POL-ACCOUNT-002·POL-SEC-001 / TC-AUTH-LOGOUT-001

기존 `POST /auth/logout` 계약을 구현했다. CSRF·출처·JSON·scope를 검증하고 암호화 서버 쿠키의 Auth 사용자와 DB 현재 세션을 확인한다. current는 local, all은 global로 폐기한다. 정상 Auth/DB 사용자 검증 뒤 사용자의 JWT로 호출하며 일반 서비스 경로에 관리 키를 쓰지 않는다. 성공 후 Auth와 CSRF의 두 쿠키를 각각 지우고 no-store 응답을 준다.

이미 폐기된 세션의 JWT로 다른 기기를 종료하는 요청을 차단한다. 전송 장애·불명확한 폐기는 성공 처리하거나 쿠키부터 지우지 않는다. 유효한 서버 쿠키의 접근 토큰 만료 경로는 401로 남기고 앞으로 갱신 경합 처리와 연결한다. 가상 개발 모드는 409로 거절하며 사용자에게 로그인/로그아웃 화면을 추가하지 않았다.

단위 총 199개(신규 11), 새 로컬 Auth 사용자 두 명/발급 세션 네 개의 통합 6항목, production 격리 HTTP 10항목과 build-check를 통과했다. 현재 세션만 폐기·같은 사용자의 다른 세션 보존, 전체 세션 폐기·다른 사용자 보존, 폐기 JWT 재사용 거절, 기존 18개 제품 테이블/기존 Auth 사용자·세션 보존 및 검사 사용자/세션 정리를 확인했다. 관리 키는 테스트 사용자 생성/정리에만 사용했다.

실제 Google/OTP·만료/갱신 경합·로그아웃 UI·계정 전환/PWA·HTTPS 브라우저 수락은 미완료다. W12-C 전체 완료가 아니다. [기획](../plans/W12-C1-logout-api.md) · [검사 증거](../quality/reports/w12-c1-logout-check-2026-10-26.json)
